# Archivo

The brand typeface, used across the marketing site and every screen in this
application. Two subsets of the variable font, weight axis only, in woff2.

Archivo is licensed under the **SIL Open Font License 1.1**, which is not this
project's licence and does not travel with it. `OFL.txt` is that licence, and it
stays beside the font files it covers: the OFL requires the notice to ship with
any distribution of the font, and this binary is a distribution of the font.

The files are served from `/app/assets/fonts/` by the signed-in application,
which is mounted at the root, so all three surfaces resolve one copy.
