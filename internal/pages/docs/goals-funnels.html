Goals

A goal is one of two things: a page somebody reached, or a custom event they sent.

A pageview goal matches a path, optionally with wildcards — /checkout/thank-you, or /blog/**. It costs nothing towards your monthly volume, because the pageview it matches has already been counted.

A custom event goal matches an event you send by name:

window.feasible('Signup')
window.feasible('Purchase', { revenue: { amount: 49.00, currency: 'USD' } })

Custom events do count towards your monthly volume, because each one is an event we received and stored.

Goals start when you create them

This is the single most common surprise, so it has its own paragraph. A goal is evaluated as events arrive, not retroactively over your history. Creating a goal today gives you a number that starts at zero today. If you need it for a campaign, create it before the campaign starts.

Funnels

A funnel is an ordered list of goals, and it counts visitors who completed each step in order within one visit. Two rules follow from that and both matter:

  • A visitor who completes step three without step two is not in the funnel at step three. Skipping a step means leaving the funnel.
  • A funnel is scoped to a visit. Somebody who signs up on Monday and buys on Thursday is two visits, and does not complete a funnel that contains both. Measure that with a goal pair rather than a funnel.

Funnel steps are evaluated by the same event stream everything else reads, so a funnel built today over goals created last month is complete from the day each goal was created — never from before it.

Revenue

Revenue is attached to a custom event with an amount and a currency. It is stored exactly as sent and never converted at write time, so a change in exchange rates can never rewrite a past quarter. Conversion, if you want it, happens at read time and shows the rate it used.
