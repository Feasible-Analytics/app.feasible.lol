There is nothing to integrate. The script is a script tag, so anything that lets you add one is supported. The list below is the ones people ask about, and the one line each needs.

WordPress

Paste the snippet into your theme's header, or into any "header and footer scripts" plugin. Do not add it to a caching plugin's "defer JavaScript" list — it is already deferred, and deferring it twice can drop the first pageview of a session.

Shopify

Online Store → Themes → Edit code → theme.liquid, inside <head>. Checkout is a separate surface: add the snippet under Settings → Checkout → Order status page additional scripts if you want purchases counted.

Next.js, Nuxt, SvelteKit, Astro

Put the tag in the root document — app/layout.tsx, app.html, Layout.astro. Client-side routing is handled by the script itself; do not also fire a manual pageview on route change, or every navigation is counted twice.

React, Vue and other single-page apps

Same rule: one tag in index.html. The script listens for history changes.

Webflow, Squarespace, Framer, Ghost

Each has a "custom code" or "code injection" field in site settings. The head section is the right one.

Google Tag Manager

It works, and we would rather you did not. A tag manager is itself the thing most often blocked, so loading our script through it turns one blockable request into two. If you must, use a Custom HTML tag firing on All Pages — Page View, with "support document.write" switched off.

Mobile apps and anything without a browser

Post to the events endpoint directly. See the APIs.

Visitors with JavaScript disabled

A no-script pixel is available and goes through the identical pipeline — the same derivation, the same session rules, the same storage. It is one image tag inside <noscript>. It cannot measure time on page or scroll depth, because nothing is running to measure them.
