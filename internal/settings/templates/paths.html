Path cleaning

Merge URLs that are really one page — an id in a path, a trailing slash — into the route you think in. Rules are applied at query time, so they fix the history you already have, and at ingest, so the path dimension stops growing. They are tried in order and the first match wins.

Rules

A pattern is a regular expression. A replacement may refer back to a capture group with $1. Deleting every rule puts the original paths back: nothing stored is rewritten.
